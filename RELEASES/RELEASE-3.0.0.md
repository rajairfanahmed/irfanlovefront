### 3. Operationalized Taste & Design Engineering (`/taste-design-engineer`)

Resolved the six fundamental flaws identified in previous AI design workflows:
1. **Verifiable Reference-to-Decision Mapping:** No more vague "study 10 references". The agent inspects actual files in `design-refs/`, logs exact paths, extracts token parameters, and documents them in an audit table.
2. **Automatic Gap Filling from Reality:** Where user specifications leave gaps, the agent never guesses or invents arbitrary colors/fonts out of thin air. It adopts concrete tokens from category-relevant brand specifications in `design-refs/`.
3. **Mandatory 3 Distinct Creative Directions:** The agent formulates three materially different concepts (e.g. Editorial Broadsheet vs. Machined Hardware Console vs. Modernist Canvas), evaluates them in a trade-off matrix, and justifies the chosen direction before locking the brief.
4. **Elimination of Forced Visual Recipes:** Double-bezel cards, bento grids, and button physics are no longer mandatory. They are versatile tools deployed only when the chosen visual concept calls for them.
5. **Context-Aware Proof Standards:** Replaced rigid avatar stacks with project-appropriate credibility evidence (real GitHub repositories, architecture schematics, and live code diffs for technical tools; verified metrics for commercial SaaS).
6. **Enforceable Route & Section Contract:** Generates exhaustive, section-by-section specifications with real production copy and 320px mobile transformations.

### 4. Zero Render-Blocking Font Architecture (`/frontend-architect`)

- **Eliminates 830ms+ Render Delays:** Strictly bans raw external `@import` in stylesheets.
- **Next.js Font Optimization:** Configures `next/font` with `display: 'swap'` for automatic self-hosting, zero layout shifts, and instant first paint.
- **Clean Vector SVG Hygiene:** Enforces valid SVG `<path d="...">` arc syntax to permanently eliminate browser console errors.

### 5. Full 100/100 Lighthouse Scores & 3/3 Agentic Browsing (`/experience-qa-auditor`)

Upgraded the QA Auditor to enforce production perfection without deleting or downgrading animations:
- **Performance (100/100):** Zero render-blocking requests, LCP < 1.2s, CLS = 0, DOM depth < 12 levels, and total DOM elements < 800.
- **Accessibility (100/100):** Strict WCAG AAA/AA contrast checks (including high-contrast CTA text on vibrant buttons and muted body text on light canvases), visible focus rings, accessible names, and `<label for="...">` associations.
- **Best Practices (100/100):** Zero console errors, clean SVG paths, and CSP/COOP security guidelines.
- **SEO (100/100):** Metadata API, OpenGraph, JSON-LD schemas, canonical tags, and valid `robots.txt`.
- **3/3 Agentic Browsing (AIO):**
  - **`public/llms.txt`:** Fully compliant markdown document starting with `# Title` H1 and a structured markdown link tree (resolves Lighthouse error *"File does not appear to contain any links"*).
  - **WebMCP Integration:** Forms and inputs annotated with `data-webmcp-tool` attributes.
  - **`public/ai-catalog.json`:** Autonomous crawler discovery manifest complying with the Agent Resource Discovery (ARD) standard.
