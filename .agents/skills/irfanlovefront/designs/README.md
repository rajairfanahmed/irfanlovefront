# Design Inspiration Library Index

## Overview
This library contains 124 curated visual references, screenshots, layout architectures, color palettes, and typography specimens. These assets serve as design evidence and creative inspiration for the UI/UX design engine.

### Core Guiding Principle: Inspiration Without Duplication
References in this library are sources of transferable principles (hierarchy, proportion, whitespace, typographic scale, color harmony, and interaction pacing). They are **never templates to clone**. The design engine extracts underlying design logic and applies it to the user's authentic content, brand identity, and technical constraints.

## 4-Step Inspiration Retrieval Workflow

When a task allows creative inspiration from this library:
1. **Identify domain and task needs:** Determine whether the project needs data density, editorial typography, atmospheric branding, or minimal hardware clarity.
2. **Retrieve targeted references:** Query the specific filenames above matching the needed dimensions (e.g. `tech-brand-colour-palette-tech-brand-col.jpg` for technical palettes).
3. **Extract transferable principles:** Isolate structural ideas (e.g. 1px hairline divider with 60% opacity; 2:1 column proportion; 48px baseline spacing).
4. **Synthesize original design:** Apply principles to the user's authentic content, brand tokens, and required framework without cloning the reference's proprietary artwork or specific pixel layout.
