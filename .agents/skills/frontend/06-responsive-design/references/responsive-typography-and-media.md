# Responsive Typography and Media

## Typography

Use readable line length, fluid sizes with bounded extremes, and line heights that suit each text role. Test long headings, small metadata, data values, and translated labels. Avoid clipping text to preserve a visual shape.

## Images

Serve dimensions and formats appropriate to actual layout. Use responsive sources where supported and provide explicit width and height or aspect ratio to reserve space. Choose crops that preserve the subject and meaning across viewport sizes.

## Video and embeds

Do not make essential content inaccessible inside a fixed-width embed. Provide responsive containers, captions or transcripts where needed, and an alternative when the media cannot be operated in the target environment.

## Icons and illustrations

Prevent icons from shrinking unexpectedly. Maintain meaningful alignment and use accessible names when the icon communicates an action. Pure decoration should not be announced.

## Performance link

Responsive image selection and font loading affect page performance. Coordinate dimensions, priority, and loading behavior with the Performance Optimization specialist.
