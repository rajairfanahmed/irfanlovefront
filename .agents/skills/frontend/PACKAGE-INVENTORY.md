# Package Inventory

## Suite-level files

- `SKILL.md`: suite role, invocation modes, skill order, ownership boundaries, invariants, and verification rules.
- `WORKFLOW.md`: end-to-end operating process and specialist handoffs.
- `README.md`: installation and package overview.

## Specialist skills

| Path | Responsibility |
|---|---|
| `00-design-engineer/` | Research, reconcile, synthesize, and specify the design direction |
| `01-frontend-architecture/` | Application architecture and frontend technical foundation |
| `02-visual-design/` | Visual system, tokens, typography, color, and theming |
| `03-structural-layout/` | App shell, page composition, grid, and layout behavior |
| `04-ui-components/` | Reusable components, contracts, semantics, and component states |
| `05-ux-interaction-design/` | User journeys, form logic, API interactions, and feedback |
| `06-responsive-design/` | Mobile-first and cross-viewport validation |
| `07-animations-motion-design/` | Purposeful motion, transitions, scroll behavior, and reduced motion |
| `08-seo/` | Technical SEO, metadata, structured data, and public-page indexing |
| `09-accessibility/` | Keyboard, assistive technology, WCAG review, and barriers |
| `10-performance-optimization/` | Measurement, runtime performance, assets, bundles, and budgets |
| `github-readme-writer/` | Accurate repository README and contributor-facing documentation |

## Shared assets

- `checklists/`: discovery, design, implementation, responsive, accessibility, SEO, performance, and release reviews.
- `templates/`: design brief, specialist specification, feature contract, page audit, architecture decision, accessibility report, performance report, and GitHub README.

## File count and scope

The ZIP is intended to be a complete, self-contained frontend skill package. It does not include user project source code, private design assets, generated implementation code, or backend skill files. The skills are stack-agnostic and must be interpreted against the actual target repository and installed framework versions.
