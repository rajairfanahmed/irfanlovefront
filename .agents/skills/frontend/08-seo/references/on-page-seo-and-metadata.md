# On-Page SEO and Metadata

## Page titles and descriptions

Create a unique, accurate title and description for each important public page. Describe the page's real purpose and content. Avoid keyword repetition, generic descriptions, and claims that the page does not support.

## Headings and content

Use semantic headings that express the content hierarchy. Headings should help readers understand the page, not simply provide a place to repeat keywords. Keep important information visible and useful to the visitor.

## Links and images

Use descriptive link text, meaningful alt text for informative images, and empty alt text for purely decorative images where appropriate. Keep internal links relevant and understandable without relying on surrounding visual styling.

## Metadata consistency

Align page title, description, canonical URL, Open Graph data, structured data, and visible content. Avoid stale metadata on dynamic detail pages. Ensure locale and publication data are accurate.

## Content integrity

Do not generate placeholder paragraphs, keyword blocks, false FAQs, or fabricated ratings. Content quality and factual accuracy take priority over metadata length targets.
