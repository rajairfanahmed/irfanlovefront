# Structured Data and Indexing

## Structured data

Add schema markup only when it accurately describes content visible on the page and the site meets the relevant policy. Choose the correct type and populate only verified fields. Never fabricate ratings, reviews, pricing, opening hours, author details, or availability.

## Dynamic data

When structured data depends on backend content, use the verified response shape and handle missing values. Do not output schema for private or personalized information. Keep the rendered data consistent with the user-visible page.

## Index control

Use canonical, noindex, pagination, and parameter rules deliberately. Search, filter, sort, session, and tracking URLs should not create uncontrolled duplicate pages. Decide which filtered views are meaningful landing pages and which should remain non-indexable.

## Validation

Validate structured data syntax and type, inspect rendered HTML, and check canonical and robots directives. Treat validator warnings in context; do not add unsupported fields just to satisfy a score.
