# Spatial Rhythm and Alignment

## Establish a spacing system

Use a consistent spacing scale and semantic layout tokens. Choose section spacing separately from component padding when the product's rhythm requires it. Avoid arbitrary values scattered through the stylesheet.

## Alignment

Align related edges and baselines. Use consistent content containers for routes that belong to the same application area, while allowing intentional full-width sections. Check that headings, body copy, fields, and action groups share meaningful alignment.

## Content width

Set maximum widths by content type. Long-form text needs a different measure from a dashboard table or visual gallery. Do not force all content into a narrow marketing container.

## Vertical rhythm

Control spacing between page title, context, filters, content, and actions. Give sections enough separation to be understood, but do not add empty space that pushes important tasks below the fold without a reason.

## Stability

Reserve space for media, async content, banners, and validation messages when practical. Sticky headers and sidebars must not cover focused elements or anchor targets.
