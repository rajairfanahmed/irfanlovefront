# Composition and Hierarchy

## Start with content and task

For each page, write its purpose, audience, primary task, essential content, supporting content, and secondary actions. Use this map to decide section order and grouping.

## Page structure

A page can use a full-width feature, split composition, editorial column, data workspace, form sequence, detail layout, or another structure. Choose based on content relationships. Avoid repeating a standard hero-plus-cards layout when the page is not a marketing page.

## Visual reading order

Create a stable reading path using headings, grouping, alignment, and spacing. Keep important actions close to the content they affect. Avoid separating a field from its label or a status from the record it describes.

## Reflow behavior

Define how columns collapse, which content changes order, what becomes a drawer or disclosure, and how dense data remains usable. Preserve semantic DOM and focus order. Do not hide essential actions simply to fit a narrow screen.

## Review

Test with real copy and representative data. Long labels, empty results, error messages, and large values often expose structural weaknesses that placeholder content hides.
