# Responsive Review Checklist

- [ ] Narrow phone, intermediate width, and wide desktop behavior reviewed.
- [ ] Breakpoints are based on content failure, not arbitrary device names.
- [ ] Main tasks and essential actions remain available.
- [ ] Text wraps without clipping or overlap.
- [ ] Images and media preserve intended crop and aspect ratio.
- [ ] Navigation and overlays remain operable.
- [ ] Tables and dense data have an intentional narrow-screen strategy.
- [ ] Forms and validation messages remain understandable.
- [ ] No unintended horizontal overflow exists.
- [ ] Sticky content does not cover focus or anchor targets.
- [ ] Keyboard, touch, pointer, zoom, and orientation are tested where relevant.
- [ ] Visual order and focus order remain sensible.
