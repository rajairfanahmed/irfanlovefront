# Repository Reconnaissance Checklist

- [ ] Repository-level and directory-level instructions read.
- [ ] Framework and exact installed version confirmed from manifests and lockfile.
- [ ] Existing route and layout structure inspected.
- [ ] Existing design tokens, typography, themes, and assets located.
- [ ] Shared components and feature boundaries identified.
- [ ] Current data-fetching and authentication integration inspected.
- [ ] Backend contracts reviewed where relevant.
- [ ] Existing tests, lint, type-check, build, and browser tooling identified.
- [ ] Environment variables and deployment assumptions reviewed without exposing secrets.
- [ ] Existing docs and decision records located.
- [ ] Requested scope and minimum required specialists identified.
- [ ] Unrelated files and generated output are excluded from the planned change.
