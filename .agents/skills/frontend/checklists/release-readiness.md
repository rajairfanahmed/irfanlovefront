# Frontend Release Readiness Checklist

- [ ] Requested features satisfy agreed acceptance criteria.
- [ ] Public and authenticated navigation works, including direct routes and refresh.
- [ ] Backend contract and permission behavior are verified.
- [ ] Primary success and failure paths have been tested.
- [ ] Empty, loading, error, and permission states are understandable.
- [ ] Responsive behavior is checked at supported widths.
- [ ] Keyboard and assistive technology checks are complete for critical journeys.
- [ ] Reduced-motion behavior is tested where motion exists.
- [ ] SEO rules and metadata are correct for public routes.
- [ ] Performance budget exceptions are understood and assigned.
- [ ] Formatter, lint, type check, tests, and production build were run where configured.
- [ ] Production environment configuration is validated without exposing secrets.
- [ ] No unrelated, temporary, or debug files remain.
- [ ] Known limitations and deferred work are documented.
- [ ] Completion report distinguishes verified outcomes from untested assumptions.
