# Accessibility Review Checklist

- [ ] Selected conformance target and scope are documented.
- [ ] Page language, title, landmarks, and heading structure are meaningful.
- [ ] Interactive controls use correct native semantics.
- [ ] Links and buttons have clear accessible names.
- [ ] All functionality is available by keyboard.
- [ ] Focus is visible, logical, and not trapped.
- [ ] Dialogs, menus, tabs, and disclosures implement expected keyboard behavior.
- [ ] Forms have labels, instructions, required state, and associated errors.
- [ ] Dynamic status changes are announced appropriately.
- [ ] Text and non-text contrast are checked.
- [ ] Color is not the only way to convey state.
- [ ] Content reflows and remains usable under zoom.
- [ ] Motion respects reduced-motion preferences.
- [ ] Automated scan results are supplemented by manual checks.
- [ ] Remaining barriers are recorded with severity and reproduction steps.
