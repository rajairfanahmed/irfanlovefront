# Performance Review Checklist

- [ ] Baseline was captured before optimization.
- [ ] Test routes, browser, device, network, build mode, and method are recorded.
- [ ] Performance budgets are documented and route-aware.
- [ ] Largest content assets use appropriate dimensions and formats.
- [ ] Media dimensions are reserved to reduce layout shifts.
- [ ] Critical resources are prioritized; noncritical resources are deferred.
- [ ] Fonts use only necessary weights and subsets.
- [ ] Route bundles and dependency cost were inspected.
- [ ] Client-side work and long tasks were reviewed.
- [ ] Third-party scripts and embeds are justified.
- [ ] Cache rules respect data freshness and privacy.
- [ ] Motion does not cause avoidable runtime cost.
- [ ] Results were measured again under comparable conditions.
- [ ] Field data and lab data are clearly distinguished.
