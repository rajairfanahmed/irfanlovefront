# SEO Review Checklist

- [ ] Route inventory identifies public, noindex, and private pages.
- [ ] Important public content is available to crawlers in the chosen rendering strategy.
- [ ] Titles and descriptions are unique and accurate.
- [ ] Canonical URLs point to the intended production URL.
- [ ] Redirects and status codes are correct.
- [ ] `robots.txt` does not block required content or assets.
- [ ] Sitemap contains valid canonical public URLs only.
- [ ] Structured data matches visible and verified page content.
- [ ] Open Graph and social preview metadata are configured where relevant.
- [ ] Internal links and image alternatives are meaningful.
- [ ] Authenticated or private content is not indexed or exposed through metadata.
- [ ] Production output has been checked, not only local development output.
