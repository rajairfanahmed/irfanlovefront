# Frontend Implementation Checklist

- [ ] Existing architecture and conventions are preserved where sound.
- [ ] The implementation matches the approved specification and acceptance criteria.
- [ ] Component APIs and feature boundaries are clear.
- [ ] API calls use verified endpoints, methods, payloads, and response types.
- [ ] Server-owned business rules and permissions are not duplicated as trusted client logic.
- [ ] Async operations have pending, success, error, and recovery behavior where relevant.
- [ ] Forms preserve user input through recoverable errors.
- [ ] Links navigate and buttons perform actions.
- [ ] Semantics, accessible names, labels, and keyboard operation are correct.
- [ ] Narrow and wide layouts are verified.
- [ ] Dependencies are justified and compatible with installed versions.
- [ ] No secrets, private data, debug output, or unrelated artifacts were added.
- [ ] Relevant formatter, lint, type, test, and build commands were run.
