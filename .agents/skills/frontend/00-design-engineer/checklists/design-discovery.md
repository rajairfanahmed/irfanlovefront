# Design Discovery Checklist

- [ ] Repository guidance and existing conventions reviewed.
- [ ] Project framework, versions, and routes identified.
- [ ] Existing public and authenticated pages inventoried.
- [ ] Product category and primary user jobs established.
- [ ] User roles and permissions understood.
- [ ] Backend architecture and API contract read where available.
- [ ] User-supplied documents and images inventoried.
- [ ] Relevant design-reference folder inventoried.
- [ ] At least ten distinct relevant references inspected when ten or more are available.
- [ ] Observations separated from inferences and unknowns.
- [ ] Existing visual system and brand constraints identified.
- [ ] Responsive, accessibility, SEO, and performance constraints identified.
- [ ] Unresolved questions and assumptions have owners.
- [ ] Scope is proportional to the request.
