# Visual Design Principles

Purpose: the reasoning that sits above color, type, and composition. Use this before and during the detailed work in the other three reference files, to keep individual decisions coherent with each other.

## Coherence and originality

Coherence means every visual decision reads as part of the same system: the same logic for when to use an accent color, the same scale for emphasis, the same vocabulary for depth. Originality comes from how precisely that system fits this product, not from avoiding familiar techniques. A grid of white cards with soft shadows is not automatically generic; it is generic when nothing about it reflects this particular product's content, audience, or brand. Ask what would have to change for this design to be wrong for a different, similarly described product. If the answer is "nothing," the direction has not been made specific enough yet.

## Hierarchy and emphasis

At any moment, something should be clearly most important on the screen, something clearly secondary, and the rest quieter still. Hierarchy comes from relative weight: size, color intensity, contrast, position, and spacing all working together, not from one property doing all the work. If three different buttons each try to be the most prominent element, none of them succeed.

## Balance, proportion, contrast, rhythm

Balance is about how visual weight is distributed across a composition, not just whether it is centered. Proportion is about whether the relative sizes of elements make sense for their importance. Contrast should be deliberate: enough to separate what matters from what doesn't, not applied uniformly everywhere until it stops meaning anything. Rhythm comes from consistent, intentional spacing and sizing intervals repeating across a page, which is what makes a layout feel considered instead of assembled piece by piece.

## Restraint versus expressive design

Both are legitimate directions. A fintech dashboard usually earns more from restraint: calm surfaces, a narrow color range, typography doing the work of hierarchy. A music festival landing page can earn more from expressive color, type, and motion. The choice is not about taste in the abstract; it is about what the product needs to communicate and to whom. State which direction the project calls for and why, early, so later decisions in color and type can be checked against it.

## Brand alignment

When a brand already exists (a logo, existing colors, an established voice), the visual system extends it rather than competing with it. When no brand exists yet, the visual decisions you make are effectively defining one; treat them with the same care, because they'll be the reference point for everything built after.

## Purposeful decoration

Every border, shadow, gradient, icon, and piece of imagery should be doing a job: separating content, indicating state, reinforcing hierarchy, or supporting the product's character. If a decorative element could be removed with no loss of clarity or meaning, that's a reason to question it, not a reason it's automatically wrong. Some products legitimately benefit from more decoration than others.

## Consistency across pages

The same kind of element should look and behave the same way everywhere it appears, unless there's a specific reason for it to differ. Consistency is what lets a user transfer what they learned on one screen to the next. It is a system property, not a page property, so check it across the whole product, not just within one view.

## Avoiding arbitrary choices

A choice is arbitrary when it could just as easily have gone another way without changing anything about the decision's justification. The fix isn't more rules, it's a clearer reason: tie the choice to something real (brand, content, audience, a supplied reference, a technical constraint) or flag it honestly as a professional recommendation with no stronger backing.

## Intentional originality versus inconsistency

A deliberate break from the established pattern, used to draw attention to something genuinely different (a destructive action, a featured item, an error state) is intentional originality. An unexplained one-off that doesn't map to anything meaningful is inconsistency. The test is whether a reader could explain why that one element looks different; if the answer is "it just does," treat it as a bug.

## Common visual design failures

- Every element competing for attention, so nothing actually stands out.
- Decoration added because it is fashionable, not because the product calls for it.
- A color or type choice copied from a reference image without adapting it to this project's content and brand.
- Inconsistent spacing or sizing that makes a product feel like several designers worked on it without talking to each other.
- Accessibility treated as a late pass instead of a constraint the design was built inside of.
- A visual system so rigid that genuinely different content gets forced into the same treatment.

The remedy in each case is the same: go back to what the product needs to communicate and to whom, and let that drive the fix.
