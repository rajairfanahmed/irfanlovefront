# Visual Design Principles

## Begin with the product's character

The visual system should communicate what the product is, who it serves, and how its interface should feel during real tasks. Visual choices are not decoration added after functionality. They affect hierarchy, comprehension, trust, and perceived effort.

## Make hierarchy visible

- Give each screen one clear primary focus.
- Use size, weight, color, spacing, alignment, and grouping consistently.
- Keep supporting information visually subordinate without making it illegible.
- Make primary and secondary actions distinguishable by hierarchy and wording.
- Use density appropriate to the task. An operations dashboard may need more information per screen than a storytelling page.

## Use contrast with intent

Contrast can come from scale, weight, tone, negative space, shape, texture, and imagery. Do not rely on color alone. Use strong contrast for important actions and restrained contrast for secondary content.

## Avoid decoration without purpose

Gradients, blur, glow, glass effects, heavy shadows, cursor effects, excessive rounding, and animation should each solve a specific communication or interaction need. Use fewer effects and apply them consistently.

## Preserve uniqueness

Do not default to the same hero, three-column feature cards, logos strip, bento grid, and CTA sequence for every project. Let content, brand, and task shape composition. Reuse principles, not a universal template.
