# Typography and Type Scales

## Select typefaces by function

Choose a typeface for the product's character, language coverage, legibility, available weights, licensing, and loading cost. One well-selected family with a useful weight range is often better than several unrelated fonts. Use a display face only when it adds a clear role.

## Build a hierarchy

Define styles for display, page title, section heading, body, supporting text, labels, metadata, and code where needed. Specify size, weight, line height, letter spacing, and maximum reading width. Use semantic text roles rather than arbitrary per-element values.

## Fluid sizing

Use fluid scales where they improve continuity between viewports. Keep minimum and maximum sizes readable and intentional. Do not use a large responsive heading simply because a formula is easy to write.

## Readability

- Keep long-form line lengths comfortable.
- Use line height appropriate to text size and density.
- Preserve clear heading hierarchy.
- Avoid low contrast, overly light weights, and very small metadata.
- Test actual content, including long titles, numeric data, and translated strings.

## Font loading

Use only required weights and subsets. Prefer efficient formats and local or trusted hosting where appropriate. Configure fallbacks with similar metrics to reduce layout shift. Do not preload every font file.
