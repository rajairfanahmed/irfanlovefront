# Hierarchy and Visual Composition

## Build a clear focal path

Identify what users should notice first, what they should understand second, and what action should be easiest to find. Each page needs a coherent reading path, not an equal-weight collection of boxes.

## Composition tools

Use alignment, scale, proportion, grouping, whitespace, repetition, contrast, imagery, and controlled asymmetry to guide attention. A strong composition can be dense or spacious depending on the task. Negative space is useful when it separates meaning; it is not a goal by itself.

## Density and hierarchy

For data-heavy interfaces, preserve enough density to support comparison and action. Use grouping, column alignment, typographic hierarchy, sticky context, and progressive disclosure. For editorial or marketing interfaces, use content rhythm and image placement to sustain reading without arbitrary section repetition.

## Visual consistency

Consistency means predictable roles and behavior, not identical appearance everywhere. A primary action should remain recognizable, while component treatment can adapt to its context. Keep repeated patterns aligned to the same design principles.

## Review method

Inspect the page at actual implementation size. Squint or blur the screenshot to assess hierarchy, then inspect text and control details at normal scale. Verify the composition with real content, not empty placeholders.
