# Design Benchmark: Awwwards (Kinetic Creative Studio)

## Visual Signature
- **Atmosphere:** Unconventional color combinations (e.g. acid green on deep charcoal, or terracotta on warm ecru).
- **Typography:** Expressive kinetic display fonts, variable font weight transitions, split-text upward entrance.
- **Scroll Physics:** Smooth normalized scrolling (Lenis / GSAP ScrollTrigger) with parallax image offsets.
- **Micro-Interactions:** Magnetic cursor following, interactive SVG distortion on hover, audio feedback toggles.
- **Bento Geometry:** Non-standard diagonal or asymmetrical grid splits breaking standard 12-column frameworks.
