# Design Benchmark: Linear (Precision Dark UI)

## Visual Signature
- **Atmosphere:** Deep obsidian surfaces with subtle warm-slate tint, not pure pitch black.
- **Borders:** Extremely thin 1px hairline borders with micro-contrast (`border-white/10`).
- **Typography:** Tight, confident neo-grotesque type with negative tracking on headings.
- **Lighting:** Ultra-subtle directional gradients (e.g., top-left radial glow on cards simulating physical overhead light).
- **Keyboard Ergonomics:** Visible keyboard shortcuts displayed in kbd badges throughout the UI (`Cmd+K`, `G then I`).
- **Micro-Interactions:** Instantaneous tab switching, zero layout jitter, high-frequency tactile micro-animations.
