# Category Guide: AI & Generative Products

## Visual & Structural DNA
- **Conversion Anchor:** Interactive model run, prompt experiment, developer API key creation.
- **Hero Archetype:** H15 (Live Interactive Prompt Sandbox / Code Runner) or H2 (Centered Glow with Live Streaming Preview).
- **Key Components:**
  1. Live prompt input bar with suggestion chips ("Summarize contract", "Generate 3D asset").
  2. Streaming response preview with syntax highlighting and copy action.
  3. Real-time latency and token generation counter pills.
  4. Side-by-side output comparison slider (Base model vs Fine-tuned).
  5. Security & data privacy compliance callouts ("Zero data retention").
- **Typography:** Space Grotesk / Inter with JetBrains Mono for prompts and code output.
- **Anti-Patterns:** Generic sparkles and robot icons, abstract claims without real output demonstrations.
