# Category Guide: Dashboard & Web Applications

## Visual & Structural DNA
- **Conversion Anchor:** Daily workflow completion, fast data manipulation, report export.
- **Hero Archetype:** H10 (Metric-Led Command Center with KPI Summary Cards).
- **Key Components:**
  1. Top metric summary bar (Total Revenue, Active Users, Error Rate) with delta indicators (`+14.2%`) and mini sparkline graphs.
  2. Data table with multi-column sorting, pagination, and batch actions.
  3. Time-series interactive chart (Area/Line) with date range filters (7d, 30d, 90d, 1y).
  4. Contextual search and filter toolbar.
  5. Collapsible sidebar navigation with keyboard shortcut tooltips.
- **Typography:** Inter or Geist with tabular monospace figures (`font-variant-numeric: tabular-nums`).
- **Anti-Patterns:** Sacrificing data density for decorative empty space, missing empty/error states.
