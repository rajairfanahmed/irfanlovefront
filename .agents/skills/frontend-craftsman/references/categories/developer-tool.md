# Category Guide: Developer Tools, CLIs & Infrastructure

## Visual & Structural DNA
- **Conversion Anchor:** CLI installation command copied, documentation opened, API key created.
- **Hero Archetype:** H1 (Split Copy / Terminal) or H15 (Executable Code Sandbox).
- **Key Components:**
  1. One-click install command snippet with copy toast feedback (`$ npm i @tool/core`).
  2. Multi-language code tab switcher (TypeScript, Python, Go, Rust, cURL).
  3. Interactive architecture diagram or telemetry pipeline.
  4. Changelog release timeline with tag badges (`v2.4.0`).
  5. GitHub star counter and open-source license badge.
- **Typography:** Fira Code or JetBrains Mono paired with Inter or Geist.
- **Anti-Patterns:** Hiding the install snippet below the fold, forcing signup before reading documentation.
