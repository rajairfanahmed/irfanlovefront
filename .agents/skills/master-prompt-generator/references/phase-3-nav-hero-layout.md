# Phase 3: Desktop Navbar, Hamburger Menu, Hero & Structural Layout

Read this file at the start of **Phase 3**. Because navbars, hamburger menus, hero sections, and layouts vary dramatically across categories, NEVER force a single default header or hero template. Present the categorized options below with `[Custom User Input]` and `[AI Recommended]`.

## Q9. Desktop Navbar Design
Ask the user how the top/primary navigation should look and behave on desktop:
- `A)` **Minimal Split Bar (Brand Left + Pill `Menu [=]` Button Right)**: No cluttered middle links on desktop; clicking the `Menu` pill opens a rich overlay menu (exact `robinsweb.net` / Awwwards agency style).
- `B)` **Floating Center Glass Island / Dynamic Pill**: Centered floating capsule (`top-6`, `rounded-full`, `backdrop-blur-md`, `1px` border) containing logo, 4-5 links, and compact CTA pill.
- `C)` **Docked Full-Width SaaS Header**: `h-16` to `h-20` bar with hairline bottom border, Brand left, centered navigation links with hover indicator, and right action buttons (`Sign In` + primary CTA).
- `D)` **Enterprise Mega-Menu Header**: Multi-column hover dropdown panels with icon descriptions and featured preview card (Stripe / Linear style).
- `E)` **E-Commerce Split Utility Header**: Announcement top bar + main bar with Search input, Category links, Account icon, Currency switcher, and slide-out Cart Drawer trigger with item counter badge.
- `F)` **Editorial Stacked Masthead**: Centered giant publication title on top row, date/edition/socials in middle rule, and horizontal category strip below.
- `G)` **Left Vertical Command Sidebar / Rail**: Fixed left navigation rail for Dashboards, AI apps, or Documentation portals.
- `H)` **Bottom Floating Dock**: macOS / Amie-style floating interactive icon/link dock anchored at `bottom-6`.
- `I)` `[Keep Existing Navbar]`: Keep the current project navigation bar.
- `J)` `[Custom User Input]`: Describe your exact desktop navbar layout, height, items, glass/border style, sticky behavior, and CTA button design.
- `K)` `[AI Recommended]`: Let AI pick the best navbar archetype for your category and reference.

## Q10. Hamburger Icon & Mobile / Overlay Menu Design
Ask how the hamburger trigger and open menu experience should work (on mobile, or on both desktop + mobile if Navbar `A` is chosen):
- `A)` **Pill Button (`Menu [=]`) Morphing to `Close [X]` + Full-Screen Curtain Reveal**: Smooth clip-path or curtain drop revealing oversized numbered links (`01 Home`, `02 Services`, `03 Work`, `04 Contact`), social links at bottom, and staggered text entrance.
- `B)` **Split-Screen Full Overlay Menu**: Left 40% shows dynamic preview image/info of the currently hovered link + contact details; Right 60% shows giant stacked navigation links.
- `C)` **Slide-In Right Frosted Glass Drawer**: `w-80` or `w-96` high-blur slide-over drawer from the right edge with backdrop dim, stacked links, and bottom CTA button.
- `D)` **Expanding Top Floating Island**: The floating navbar pill smoothly expands downward in-place (`height` + `opacity` spring animation) to reveal navigation cards inside the same capsule.
- `E)` **Minimal 2-Line Architectural Burger + Clean Accordion Sheet**: Ultra-clean 2-line SVG icon (`w-6`) that rotates into an `X` and opens a crisp top-down sheet.
- `F)` **Mobile Bottom Sheet Drawer**: Touch-friendly swipeable bottom sheet anchored to the thumb zone on mobile viewports (`<768px`).
- `G)` `[Custom User Input]`: Describe your exact hamburger button style, open/close animation, menu background color/glow, and link layout.
- `H)` `[AI Recommended]`: Let AI pair the ideal menu overlay with your chosen desktop navbar.

## Q11. Hero Section Architecture
Do not enforce a fixed 60/40 split or CLI box. Offer these distinct hero archetypes:
- `A)` **Layered Giant Display Title + Center Overlapping Cutout Portrait (`robinsweb.net` Archetype)**:
  - Layer 1 (Back): Deep dark canvas with warm radial orange/accent spotlight glow (`radial-gradient`).
  - Layer 2 (Middle): Giant viewport-spanning condensed uppercase display text (e.g., `WEB DESIGNER` / `RAJA IRFAN AHMED`) across the background.
  - Layer 3 (Front Center): High-res cutout portrait photo (`z-20`) overlapping the lower center of the giant display title.
  - Layer 4 (Foreground Corners): Floating badge/intro text on left, availability/CTA or stats on right, leading directly into a full-width Infinite Marquee strip at the bottom edge.
- `B)` **Asymmetric 60/40 Editorial Split**: Left 60% bold headline, lead copy, dual CTAs, and trust metrics; Right 40% framed portrait card, interactive widget, or visual composition.
- `C)` **Centered High-Impact SaaS Headline + 3D Tilted Product Mockup**: Centered badge, display headline, subcopy, dual CTA buttons, and a large perspective-tilted (`rotateX`) glassmorphic dashboard/interface preview with glowing top border.
- `D)` **Full-Bleed Cinematic Video / Showreel / 3D Canvas Hero**: 100vh visual canvas with bottom-left anchored oversized typography and minimal scroll indicator.
- `E)` **E-Commerce Editorial Campaign Hero**: Split full-height lookbook photography on one side, collection title, featured product callout, and `Shop Collection` CTA on the other.
- `F)` **Bento Showcase Hero**: Headline paired immediately with a 4-to-5 cell asymmetric Bento grid showing live micro-features, metrics, and media.
- `G)` **Swiss Poster / Typography-Only Hero**: Exposed `1px` grid hairlines, extreme typographic scale contrast, zero decorative imagery, and precise coordinate labels.
- `H)` `[Custom User Input]`: Describe your exact hero layering, image placement, text alignment, badges, and buttons.
- `I)` `[AI Recommended]`: Let AI design the hero composition based on your category and reference.
